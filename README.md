# openSUSE Adaptive Branding

The openSUSE brand identity system — **We build the tools so you can build the world.**.

## openSUSE Adaptive Branding Guide

A brand identity reference for the openSUSE Project and its flavors/distributions. It covers colors, typography, logo usage, and print and digital asset rules.

### What's inside
- **Two color layers:** a bright *Flavor Brand* for distributions (Geeko Green, Turquoise Teal, Yarrow Yellow, …) and a deeper *Project Brand* for community materials. The Project Brand is anchored by the heritage navy "Pine" and a neutral range from Ink to Mist.
- **Gradient rules:** pair adjacent hues, avoid opposite ones, and run gradients from bottom-left to top-right.
- **Typography:** the SUSE font family, with set weights and line heights for headings, body text and code.
- **Logo gallery:** the openSUSE mark plus Tumbleweed, Leap, MicroOS, Kalpa and Slowroll, each with its own signature color, and examples on light and dark backgrounds.
- **Asset specs:** stickers (Bagel Beige border, ready for die-cutting), wallpapers (low-poly gradients, 4K minimum) and downloadable flyers.


## Contributing

Contributions are welcome! Whether it's fixing a typo, improving the design, adding new brand assets, or proposing changes to the guidelines, we welcome the help.

### How to Contribute

1. **Fork this repository** — click the Fork button at the top right of this page.

2. **Clone your fork:**
   ```bash
   git clone https://github.com/<your-username>/opensuse-branding.git
   cd opensuse-branding
   ```

3. **Create a branch** for your changes:
   ```bash
   git checkout -b my-improvement
   ```

4. **Make your changes** — edit HTML, CSS, add/update SVGs, improve copy, etc.

5. **Test locally** — open `index.html` in a browser to preview. No build step needed; it's plain HTML/CSS/JS.

6. **Commit and push:**
   ```bash
   git add -A
   git commit -m "Describe what you changed"
   git push origin my-improvement
   ```

7. **Open a Pull Request** — go to your fork on GitHub and click "Compare & pull request". Describe what you changed and why.
