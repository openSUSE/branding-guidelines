Container cheat sheet
podman run -d -p 8080:80 nginx

podman pull opensuse/tumbleweed
Grab an official openSUSE base image.
podman ps -a
See what's running — and what stopped.
podman auto-update
Pull new images and restart labelled containers.

Drop Quadlet files here to run containers as services.
sudo transactional-update pkg in htop
Add a host package without breaking immutability.
sudo transactional-update rollback
Return to the last known-good host state.
distrobox create -i tumbleweed
