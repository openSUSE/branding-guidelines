openSUSE transactional-update

Update atomically.
Roll back cleanly.

Immutable systems share one update workflow: every change lands in a fresh Btrfs snapshot. If an update misbehaves, the previous system is still there.

Leap
Stable, enterprise-aligned base with a transactional server role.
MicroOS
Read-only, self-updating host for containers and edge.
Kalpa
Immutable KDE Plasma desktop built for daily use.
Other downstream flavors from openSUSE may use the same transactional-update workflow.
