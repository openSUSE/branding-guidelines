Admin cheat sheet

Run it like a pro.

sudo zypper patch
Apply only official security and bug fixes.
zypper lp
List pending patches before a maintenance window.
zypper ps -s
Find services still running old libraries after updates.
sudo systemctl enable --now cockpit.socket
Manage the box from your browser on port 9090.
sudo firewall-cmd --list-all
Check exactly which ports are open.
journalctl -p err -b
Show only errors since the last boot.
sudo snapper create -d "pre-change"
Take a manual snapshot before risky work.
sudo zypper --releasever=<ver> dup
Upgrade Leap to the next release in place.
