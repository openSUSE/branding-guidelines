THE IMMUTABLE ADVANTAGE

What it doesn't stop.

A read-only core changes what an attacker can make stick. It does not stop the first compromise.

INITIAL ACCESS
A vulnerable web app
An exposed SSH, database, or admin panel
Weak or stolen credentials
Phishing payloads
An unpatched network daemon
AFTER ACCESS
Code execution in memory
Data theft from /home, /var, databases, and volumes
Persistence in user config, cron, systemd user units, container volumes, or cloud credentials
Kernel privilege escalation
Re-exploiting the same hole after every reboot
BOTTOM LINE
Immutability raises the cost of a deep, lasting takeover and makes cleanup easier. It is not a shield against the first compromise.
