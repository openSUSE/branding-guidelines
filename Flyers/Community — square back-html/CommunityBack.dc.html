Report a bug
Good details get bugs fixed fast. Attach the output of:
cat /etc/os-release
Which release and version you run.
inxi -Fxz
Hardware summary, private data masked.
journalctl -b -p err
Errors from the current boot.
rpm -q <package>
Exact version of the broken package.
bugzilla.opensuse.org
Fix a package
Your first contribution, in five steps with osc:
osc branch <project> <pkg>
Make your own copy on OBS.
osc checkout home:<you>…
Download it to edit locally.
osc build
Test-build in a clean chroot.
osc commit
Push your change back to OBS.
osc submitrequest
Ask maintainers to merge it.
