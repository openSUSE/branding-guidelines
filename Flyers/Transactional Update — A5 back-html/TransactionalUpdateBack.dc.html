transactional-update cheat sheet

Stage it. Reboot. Roll back.

Each transactional-update command creates a new snapshot. Nothing touches the running system until you reboot.

sudo transactional-update
pkg install <pkg>
Install a package in a new snapshot.
sudo transactional-update
pkg remove <pkg>
Remove a package.
sudo transactional-update
pkg update <pkg>
Update a single package.
sudo transactional-update
dup
Update the system to the latest snapshot.
sudo transactional-update
patch
Apply available patches.
sudo transactional-update
--continue pkg install <pkg>
Add to the pending snapshot.
sudo transactional-update
rollback last
Return to the last working snapshot.
sudo transactional-update
rollback <number>
Return to a specific snapshot.
sudo transactional-update
cleanup
Remove old snapshots.
sudo snapper list
Inspect snapshots before rolling back.
sudo journalctl -u
transactional-update.service
Read the automatic update log.
sudo reboot
Boot into the staged snapshot.
