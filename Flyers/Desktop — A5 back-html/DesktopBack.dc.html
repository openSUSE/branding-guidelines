Desktop cheat sheet

Ten commands worth knowing.

sudo zypper dup
Update Tumbleweed or Slowroll to the latest snapshot.
sudo zypper up
Install the latest updates on Leap.
zypper se <term>
Search the repositories for a package.
sudo zypper in <pkg>
Install it, dependencies included.
opi codecs
Add full multimedia codec support.
zypper info <pkg>
Version, repo and dependencies at a glance.
flatpak install flathub <app-id>
Get sandboxed apps — the easy way on Kalpa.
snapper list
See every system snapshot taken before changes.
sudo snapper rollback
Undo a bad update after booting an older snapshot.
sudo transactional-update dup
Update Kalpa atomically; applies on reboot.
Prefer clicking? YaST and Myrlyn
do all of this with a GUI.
