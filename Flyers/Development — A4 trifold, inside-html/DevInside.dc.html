01 · Set up

A dev box in minutes.

sudo zypper in -t pattern devel_basis
Compilers, make and the core build tools in one go.
sudo zypper in git osc
Version control plus the Build Service client.
sudo zypper si -d <pkg>
Install everything needed to build a package from source.
distrobox create -i leap
Test against stable Leap while you develop on Tumbleweed.
zypper wp <file>
Which package provides a missing header or library?
02 · Package

Ship with the Build Service.

osc mkpac <name>
Create a new package in your home project.
osc build
Build locally in a clean, reproducible root.
osc commit -m "…"
Upload — OBS builds for every target you enabled.
osc results
See build status per distro and architecture.
osc buildlog <repo> <arch>
Read the full log when a build fails.
03 · Contribute

Get it into the distro.

osc branch openSUSE:Factory <pkg>
Fork a Tumbleweed package to improve it.
osc vc
Write the changelog entry reviewers expect.
osc submitrequest
Send it for review — openQA tests it before release.
osc rq list -M
Track the requests you've sent.
Docs: en.opensuse.org/openSUSE:Packaging_guidelines
